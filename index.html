The error is on screen.
The cause is somewhere else.

A build fails and 400 lines scroll past. The real reason is usually small: a variable renamed in code but never set in production, a file renamed from Header.tsx to header.tsx that only breaks on Linux, a lockfile that drifted from package.json.

Finding it means correlating the log, the commit diff and the settings by hand, often late at night. A chatbot can guess, but a confident wrong guess is worse than no answer.

So this tool shows its work. Each claim comes with the exact line it relies on, and a check confirms that line exists.

How it works

Five steps. The last one is the one that matters.

  1. 01

    Collect

    Pulls the failed deploy’s build log, the diff between the last good commit and the failed one, and the names of environment variables that changed. Values are never read.

  2. 02

    Redact

    Strips keys, tokens, JWTs, connection strings and emails before anything leaves your machine. Try it below.

  3. 03

    Reduce

    Keeps the error region of long logs and ranks diff files by whether the log mentions them, so the model sees signal instead of 10,000 lines of noise.

  4. 04

    Diagnose

    An LLM answers in a strict format: cause, evidence quotes, fix, confidence. It is told to copy quotes character for character and to say so when it is unsure.

  5. 05

    Verify

    Each evidence quote is searched for in the original log, diff and env changes. If one isn’t there, the diagnosis is downgraded to low confidence and flagged. This is the step you can test in the demo above.

Limits

      
What it doesn’t do yet.

      
    
        
  • Vercel is the only supported host.
    • 
        
  • Build failures only. No runtime errors, cron jobs or webhooks.
    • 
        
  • Deleted env vars can’t be seen through Vercel’s list API.
    • 
        
  • It diagnoses. It doesn’t open fix pull requests yet.
    • 
        
  • The evidence check catches made-up quotes, not flawed reasoning. Treat the answer as a strong lead.
    •

git clone https://github.com/CyVenom/Root-Cause-Fix.git
cd Root-Cause-Fix
npm test
npm run diagnose -- packages/core/fixtures/missing-env-var --mock

  
Needs Node.js 22.18+. No dependencies to install. The --mock flag runs offline for free; add an API key in .env to use a real model.
